# Furniture Planner 3D — 0.1.3

[English](README.md) · [Общий комплект](../README.ru.md)

Расстановка готовых модулей в прямоугольном помещении и печать пронумерованной монтажной схемы с текущего 3D-ракурса. Импорт STL, 3MF и проектов/библиотек JSON из FurnitureMaker.

### Быстрый старт
1. Задайте реальные размеры помещения X, Y, Z в миллиметрах.
2. Импортируйте модели. Для STL/3MF укажите исходный масштаб до импорта (например, 20 для 1:20); JSON FurnitureMaker восстанавливает масштаб автоматически.
3. Нажмите «+» для добавления экземпляра. Щелчок по названию в библиотеке только выделяет модель.
4. Выберите шкаф в помещении. Привяжите его к стене A, B, C, D или углу A–B, B–C, C–D, D–A. Задайте высоту и положение вдоль стены. Для островов и нестандартных форм используйте свободный режим.
5. Присвойте модулям номера и сохраните `.planner.json`.
6. Поверните камеру и нажмите «Печать / PDF». Выберите A4/A3, цвет или Ч/Б и при необходимости включите список модулей.

### Управление мышью
ЛКМ — выбор/перемещение; Shift + ЛКМ — высота; ПКМ — вращение камеры; колесо — масштаб; средняя кнопка — сдвиг камеры.

Стены постоянны: A — задняя (+Y), B — правая (+X), C — передняя (Y=0), D — левая (X=0). Автоматическая ориентация рассчитана на модели FurnitureMaker. Стыковка работает по габаритам, автоматической проверки пересечений нет. Схема дополняет проверенные рабочие чертежи и монтажные размеры.

### Установка и сборка Windows

Установите `FurniturePlanner3D-Setup-0.1.3-x64.exe` из Releases после публикации файла. Для установленного приложения отдельно ставить инструменты сборки не требуется. Для сборки из исходников: Node.js LTS с npm и интернет для получения зависимостей. Сборка использует Electron и electron-builder. Запустите `BUILD_SETUP.bat`, результат ожидается в `dist/`. См. [оригинальную инструкцию сборки](README_WINDOWS_RU.txt).
