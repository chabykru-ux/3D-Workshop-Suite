PLAQUEMAKER 3D v1.3.1
===================

КАК ЗАПУСТИТЬ
1. Распакуй архив в любую папку на Windows.
2. Дважды щёлкни index.html — откроется Chrome или Microsoft Edge.
3. Программа полностью работает без интернета.

КАК СДЕЛАТЬ ТАБЛИЧКУ
1. Установи ширину, высоту, толщину основания и скругление.
2. Отметь галочками бортик, отверстия, строки текста и декоративную линию.
3. Введи любые надписи, размеры шрифтов и отступы сверху.
4. При изменении параметров предпросмотр перестраивается автоматически.
5. Вращай модель мышью, прокручивай колёсико для масштаба.
6. Нажми «Создать 3MF» для цветного проекта либо «Создать STL» для одноцветной печати.
7. Открой файл в Creality Print. Проверь габариты, цвета, профиль принтера и слои.

ЦВЕТНАЯ ПЕЧАТЬ
- В 3MF содержится одна составная модель с отдельными частями:
  основание, бортик, верхние надписи, нижние надписи, декоративная линия.
- Каждая часть получает свою метку цвета (при наличии).
- Creality Print может не распознать соответствие цветов и слотов CFS автоматически.
  Назначь нужные катушки вручную, если потребуется.
- Для углублённого текста отдельной цветной части нет: это гравировка в основании.
  Два независимых цвета текста работают для выпуклых надписей.

ТЕХНИЧЕСКИЕ ОСОБЕННОСТИ
- Размеры в миллиметрах.
- Текст превращается в настоящую 3D-геометрию; текстовые онлайн-сервисы не нужны.
- Контуры аппроксимируются сеткой 0.20–0.50 мм, поэтому мелкие буквы могут быть
  ступенчатыми. Уменьшай шаг сетки для лучшего результата.
- STL создаётся как объединённая геометрия, без цветовых данных.
- 3MF хранит отдельно геометрию и цветовые материалы частей.
- JSON-файл проекта сохраняет настройки и позволяет открыть их позже.
- Номер телефона по умолчанию 054-000-0000 — только пример, замени его на свой.
- Никаких внешних JS-библиотек, сервера, учётной записи, подписки и сетевого доступа.

ОГРАНИЧЕНИЯ ПЕРВОЙ ВЕРСИИ
- Цвета в 3MF не гарантируют автоматический выбор филамента в любом слайсере.
- Для очень тонких шрифтов и мелких цифр требуется визуальная проверка слоёв в Creality Print.
- Упрощённые ступенчатые границы букв определяются выбранным шагом сетки.
- 3MF использует стандартную структуру составного объекта; некоторые слайсеры
  могут интерпретировать её по-своему. Если возникнет проблема, открой STL.
- Это конструктор табличек, а не универсальный CAD-редактор.

ФАЙЛЫ
index.html — главное окно
styles.css — оформление
app.js — генератор модели и интерфейс
service-worker.js — офлайн-кэш для HTTPS/PWA

ПОЛЕЗНО: если далее захотим получить обычный Windows Setup.exe,
эту HTML/CSS/JS-версию можно упаковать в Electron без переписывания логики.

ИЗМЕНЕНИЯ В 1.1
- Исправлен экспорт 3MF: соседние треугольники используют общие вершины
  (раньше Creality Print предупреждал об открытых рёбрах).
- Добавлен отдельный цвет для нижних надписей; верхние и нижние
  надписи экспортируются отдельными деталями 3MF.
- Если включена разделительная линия, цвет каждой строки определяется
  её положением относительно линии. Если линия выключена, строки 1 и 2
  относятся к верхнему блоку, строки 3 и 4 — к нижнему.
- Проекты v1.0 открываются: нижний цвет подставляется по умолчанию.
- Исправления не меняют общую схему печати и размеры таблички.


НОВОЕ В 1.2: БИБЛИОТЕКА ШРИФТОВ
- 12 вариантов: Arial, Times New Roman, Georgia, Courier New, Trebuchet MS,
  Segoe Script, Segoe Print, Gabriola, Monotype Corsiva, Comic Sans MS, David, Gisha.
- Выбирай из выпадающего списка или нажимай на карточку шрифта.
- Фильтры: Все, Русский, English, Иврит.
- Надписи и 3D-модель перестраиваются автоматически.
- Для иврита используется направление справа налево при построении букв.
- Шрифты Windows не включены в архив: приложение использует установленные
  в твоей системе. Отсутствующие шрифты браузер заменит похожими.
- Для гарантированного конкретного начертания нажми «Импортировать свой TTF/OTF».
  Импортированные шрифты загружаются только в текущий сеанс (все данные локальные).
  При повторном открытии JSON-проекта со своим шрифтом импортируй файл снова.
- Для русского/английского хорошо подходят Arial, Times, Segoe Script/Print.
- Для иврита можно попробовать David и Gisha, а также Arial и Times.
- Поддержка символов зависит от реального установленного шрифта.
- Не все рукописные штрихи подходят для сопла 0,4 мм: проверяй слои и толщины.
- Свои импортированные шрифты можно использовать, только если у тебя есть
  право на их использование.


ИСПРАВЛЕНИЕ 1.2.1 (23.11.2026)
- Исправлена ошибка: в 1.2 выбранный шрифт отображался в библиотеке, но
  подготовка геометрии принимала только четыре шрифта старой версии.
  Остальные подменялись Arial.
- Теперь все 12 вариантов и импортированный TTF/OTF проходят в Canvas,
  живой 3D-просмотр, STL и 3MF без подмены в коде программы.
- Техническая проверка: разные шрифты действительно создают отличающиеся
  треугольные сетки букв; 3MF остаётся замкнутым.
- Шрифты самой Windows: фактическое начертание зависит от их наличия в ОС.
  Если нужного шрифта нет, можно загрузить свой TTF/OTF через кнопку импорта.
- Важная рекомендация: удаляй старую папку только после проверки новой,
  распаковывай v1.2.1 в отдельную папку, чтобы не открывать старый app.js.


НОВОЕ В 1.3: ДВА ВИДА ТАБЛИЧЕК
- В самом верху настроек можно выбрать Обычную табличку или С номером.
- «Обычная» воспроизводит поведение проверенной версии 1.2.1.
- «С номером» добавляет вертикальный разделитель и правое поле.
- Размер правого поля (мм), надпись справа, размер, высота и жирность доступны
  только при выборе вида «С номером».
- Шрифт для правого поля — из общей библиотеки шрифтов.
- Справа можно написать номер комнаты, кабинета, слово на русском, английском
  или иврите. Горизонтальная линия и старые надписи остаются слева.
- Цвет правой надписи задаётся независимо в блоке «Цвета для 3MF».
- Вертикальная и горизонтальная линии получают общий цвет «Разделительные линии».
- Обычная табличка экспортируется по-прежнему, без лишних деталей справа.
- На Creality CFS Lite доступны четыре катушки: несколько цветовых деталей
  можно назначить одной и той же катушке в Creality Print.
- Проекты версии 1.2.1 открываются как обычные таблички; новый тип можно выбрать
  вручную. Проект можно сохранить в JSON с выбранным видом.
- Важно: экспорт проверен программно; окончательную проверку в Creality Print
  и на принтере проведи перед печатью.


v1.3.1 — интерфейс
На широком экране правая панель с 3D-предпросмотром закреплена при прокрутке настроек. На узких экранах сохранена прежняя компоновка. Геометрия и экспорт не изменены.
