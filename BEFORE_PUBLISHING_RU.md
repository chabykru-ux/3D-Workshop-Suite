# Проверки перед публикацией

Этот архив — подготовленная структура репозитория, не опубликованный репозиторий. Исходники четырёх комплектов сборки сохранены побайтово; добавлены только Markdown-инструкции и .gitignore.

- [ ] Проверить, что четыре готовых Setup.exe действительно собраны и запускаются на Windows x64; проверить экспорт в слайсер и печать Planner.
- [ ] Решить, оставлять ли имя `CHABANY OLEG` в демонстрационном тексте PlaqueMaker (`app/app.js`, `app/index.html`). Проверить также встроенные примеры STL/3MF, скриншоты и локальные пути на личные данные. Автоматический поиск по текстовым файлам не является полной проверкой приватности.
- [ ] Выбрать собственную лицензию проекта (например, MIT, если автор согласен с её условиями), добавить LICENSE и необходимые уведомления. Не объявлять комплект open source без выбранной лицензии.
- [ ] Проверить лицензии реально включённых в установщики сторонних компонентов Electron, Chromium, Python, Tesseract и библиотек DrawingMaker, сохранить необходимые уведомления. Проверка лицензий не выполнена.
- [ ] Не добавлять в Git историю личных проектов, node_modules, dist, среды сборки и готовые EXE. Использовать GitHub Releases для установщиков.
- [ ] Добавить проверенные скриншоты без личных данных по желанию.
- [ ] При публикации приложить четыре готовых EXE; опционально один общий ZIP с ними. Указать отсутствие цифровой подписи, если применимо.

Предлагаемое имя репозитория: `3D-Workshop-Suite`. Английские README являются основными; русские доступны по ссылке в начале каждого файла. Исходный пользовательский интерфейс программ не переводился и не менялся.
