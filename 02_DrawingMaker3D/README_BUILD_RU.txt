DrawingMaker 3D v0.6.0 — сборка Windows Setup (x64)

1. Полностью распакуй ZIP в отдельную папку. Желательно короткий путь, например C:\DrawingMakerBuild.
2. На компьютере сборки нужны Python 3.12 x64 и Tesseract OCR с английским языком. Они уже установлены, если ты работал с v0.6.0. Если нет — используй INSTALL_PYTHON.bat и INSTALL_OCR.bat.
3. Запусти BUILD_SETUP.bat. Для сборки требуется интернет. Создается отдельное окружение .buildenv, устанавливаются библиотеки и PyInstaller, копируется локальный Tesseract, собирается самостоятельный EXE. После этого программа сама проверит все 25 встроенных примеров, включая экспорт STL и 3MF, и только при успехе будет собран установщик Inno Setup. Если Inno Setup отсутствует, скрипт попробует установить его через winget. При необходимости установи Inno Setup 6 вручную с https://jrsoftware.org/isdl.php.
4. Результат: dist\DrawingMaker3D-Setup-0.6.0-x64.exe. Это единственный файл, который нужен конечному пользователю. После установки Python, Tesseract и Интернет отдельно не нужны. Программа устанавливается для текущего пользователя и создает ярлыки на рабочем столе и в меню Пуск. Удаление — стандартное через параметры Windows.
5. Если сборка остановится, пришли build-log.txt и self-test.txt (если есть). Не удаляй проверенную экспериментальную версию.

Ядра engine.py, legacy_engine.py, bracket_engine.py, round_engine.py и интерфейс app.py сохранены без изменений. Добавлена отдельная оболочка Windows. В заголовке программы остаётся Experimental — это название проверенной версии, не изменение геометрического ядра.
Установщик не подписан цифровой подписью. При публикации проверь лицензии включенных сторонних компонентов и условия использования Inno Setup. Сборка Windows не выполнялась в Linux; автоматическая проверка будет проведена на компьютере сборки.
