Furniture Planner 3D v0.1.3 — Windows x64

1. Перед переходом сохрани готовые кухни кнопкой «Сохранить проект» (JSON).
2. Полностью распакуй архив, запусти BUILD_SETUP.bat. Нужны Node.js LTS и интернет для сборки. Если Node.js уже установлен, повторная установка не нужна.
3. Результат: dist\FurniturePlanner3D-Setup-0.1.3-x64.exe.
4. Установи обычным способом. Интернет и Node.js после установки не нужны.
5. Открой сохранённый проект. Проверь импорт, привязку и печать.

В Windows-версии используется печать Electron/Windows, а не окно предпросмотра Chrome. Для PDF выбери Microsoft Print to PDF, если он установлен. Проверь выбор бумаги и ориентацию в диалоге печати. Реальная печать и сборка Setup должны быть проверены на Windows.
Исходные файлы приложения v0.1.3 сохранены без изменений, добавлены оболочка Electron и иконка установщика. Установщик не подписан цифровым сертификатом. Для запуска без сборки открой app/index.html.
