Furniture Planner 3D v0.1.3 — экспериментальная автономная версия

Запуск: распакуйте весь архив, откройте index.html в Chrome или Edge.
Интернет не нужен. Можно запустить START_WINDOWS.bat.

1. Задайте длину X, глубину Y и высоту Z помещения в реальных мм.
2. Импортируйте STL, 3MF, JSON проекта или библиотеки FurnitureMaker.
   Для STL/3MF задайте исходный масштаб до импорта (например, 20 для 1:20).
   JSON FurnitureMaker восстанавливает масштаб автоматически.
3. Щелчок по названию в библиотеке только выделяет строку. Только кнопка
   «+» добавляет экземпляр в сцену. Перетаскивание из библиотеки отключено.
   Явная кнопка «Копия» для уже размещенного модуля сохранена.
4. Выберите модуль в сцене или в списке размещенных модулей.
   Стены: A = задняя (+Y), B = правая (+X), C = передняя (Y=0), D = левая (X=0).
   Буквы постоянны, независимо от камеры. На виде сверху видны все четыре.
   Выберите стену: задняя сторона модуля фиксируется у стены, фасад
   разворачивается внутрь. Перемещение мышью только вдоль выбранной стены.
   Можно ввести точное расстояние вдоль стены и высоту Z от пола.
   Для угловых шкафов выберите A–B, B–C, C–D или D–A: обе горизонтальные
   координаты фиксируются. Высота остается регулируемой.
   При изменении габаритов комнаты закрепленные модули обновляют положение.
   «Свободно» снимает привязку, сохраняет положение и разрешает ручной поворот.
5. ЛКМ по шкафу — выбор и перемещение. Shift+ЛКМ — изменение высоты.
   ПКМ — вращение камеры, колесо — масштаб, средняя кнопка — сдвиг камеры.
   Слева доступны точные координаты, номер, копирование, скрытие и удаление.
6. Сохраните проект .planner.json для дальнейшего редактирования.
   Старые проекты Planner открываются; старые привязки сохраняются.
7. Поверните сцену до нужного ракурса, нажмите «Печать / PDF».
   A4/A3, цвет или Ч/Б, список модулей по желанию. В списке печатается
   также обозначение стены или угла. Для PDF выберите сохранение в PDF
   в системном диалоге печати.

Ограничения:
- Комната прямоугольная. Можно использовать любые 1–4 стены.
- Ориентация автоматической привязки рассчитана на модели FurnitureMaker.
  Угловой шкаф FurnitureMaker имеет исходный задний угол +X/+Y.
  Для угловых столешниц JSON учитывается зеркальность. Для STL/3MF
  столешниц и сторонних моделей с иной ориентацией — свободное размещение.
- Стыковка выполняется по габаритам, не по сложным контурам. Автоматического
  контроля пересечений нет. Если модуль больше комнаты, появится предупреждение.
- Печатная схема показывает компоновку; рабочие монтажные размеры и крепления
  проверяются по производственным чертежам.

Примеры находятся в examples. Можно также нажать «Демо».
Проверено в Chromium с программным Canvas: импорт 3MF и JSON, отсутствие
копий при щелчках по библиотеке, добавление +, 4 стены и 4 угла,
перемещение вдоль стены, точная высота, изменение размеров комнаты,
сохранение и открытие проекта, освобождение и поворот, печать A4 (1 лист).
Аппаратный WebGL и физический принтер Windows требуют проверки на месте.
