# DrawingMaker 3D — 0.6.0 (FIXED3 build)

[English](README.md) · [Общий комплект](../README.ru.md)

Преобразование поддерживаемых технических чертежей в модели для 3D-печати. Программа использует распознавание текста и шаблоны геометрии, а не универсальную реконструкцию. Входные файлы: PNG и одностраничный PDF.

Поддерживаются прямоугольные блоки, пластины, цилиндры, детали с одной ступенью или наклоном, специальный уголок 90° со скруглёнными концами, шар, полушарие, конус и усечённый конус. Сквозные и глухие вертикальные отверстия доступны для соответствующих типов деталей.

### Быстрый старт
1. Откройте готовый пример или подготовьте чёткий чертёж с видами FRONT, SIDE и TOP, английскими обозначениями размеров в мм.
2. Откройте файл и нажмите «Анализ и 3D».
3. Сверьте распознанные размеры, отверстия и модель с исходником.
4. Экспортируйте STL или 3MF и проверьте масштаб и форму в слайсере.

Синтаксис размеров и ограничения каждого типа приведены в [исходной инструкции](README_RU.txt) и приложенных примерах. Резьбы и произвольные сложные формы не поддерживаются. Не используйте программу для ответственных деталей без соответствующей инженерной проверки.

### Установка и сборка Windows

Установите `DrawingMaker3D-Setup-0.6.0-x64.exe` из Releases после публикации файла. Для установленного приложения отдельно ставить инструменты сборки не требуется. Для сборки из исходников: Python 3.12 x64, Tesseract OCR с английским языком, Inno Setup 6 и интернет для зависимостей. Скрипт упаковывает Python и Tesseract и выполняет самопроверку перед созданием установщика. Запустите `BUILD_SETUP.bat`, результат ожидается в `dist/`. См. [оригинальную инструкцию сборки](README_BUILD_RU.txt).
