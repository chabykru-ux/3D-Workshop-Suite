# FurnitureMaker 3D — 0.2.3

[English](README.md) · [Общий комплект](../README.ru.md)

Параметрический конструктор масштабной мебели для физического макета и цифровой компоновки. Нижние и навесные шкафы, пеналы, ящики, дверцы, ниши, угловые шкафы 45° и 90°, четыре формы столешниц, включая диагональный внутренний угол.

### Быстрый старт
1. Выберите шаблон, задайте реальные габариты в миллиметрах и масштаб (по умолчанию 1:20).
2. Настройте секции, двери, ящики, ручки, ножки или цоколь и цвета. Сумма высот секций должна соответствовать высоте корпуса.
3. Сохраните модуль или экспортируйте библиотеку в JSON. Регулярно делайте резервную копию библиотеки.
4. Экспортируйте STL или многоцветный 3MF для слайсера либо импортируйте проект/библиотеку JSON в Furniture Planner 3D для автоматического восстановления масштаба.

Это конструктор масштабных моделей, а не система расчёта раскроя настоящей мебели. Двери и ящики не открываются. Открытые ниши в угловых шкафах не поддерживаются. Проверяйте печатаемость, размеры и поддержки; отображаемый объём не равен расходу филамента.

### Установка и сборка Windows

Установите `FurnitureMaker3D-Setup-0.2.3-x64.exe` из Releases после публикации файла. Для установленного приложения отдельно ставить инструменты сборки не требуется. Для сборки из исходников: Node.js LTS с npm и интернет для получения зависимостей. Сборка использует Electron и electron-builder. Запустите `BUILD_SETUP.bat`, результат ожидается в `dist/`. См. [оригинальную инструкцию сборки](README_WINDOWS_RU.txt).
