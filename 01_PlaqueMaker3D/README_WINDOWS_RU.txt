PlaqueMaker 3D v1.3.1 — сборка Windows x64

1. Распакуй ВЕСЬ архив, например в C:\PlaqueMaker3D.
2. Нужен Node.js LTS (рекомендуется 22 или 24) с npm и интернет для первой сборки.
3. Запусти BUILD_SETUP.bat двойным щелчком. Либо в терминале в папке с package.json:
   npm install
   npm run dist
4. Итог: dist\PlaqueMaker3D-Setup-1.3.1-x64.exe.
   Установщик создаёт ярлыки на рабочем столе и в меню «Пуск».
5. Для проверки приложения до упаковки: npm start (после npm install).

Установленная программа работает без интернета. Сохранение файлов осуществляется обычным механизмом загрузки Chromium/Electron. Установщик не подписан сертификатом: Windows может показать предупреждение SmartScreen. Сборка EXE производится на твоём Windows-компьютере; этот архив содержит исходники, не готовый EXE.

При ошибках сборки сохрани текст терминала. Если Windows не разрешает создание символических ссылок при распаковке инструментов electron-builder, включи режим разработчика Windows или запусти терминал с правами администратора. Не отключай антивирус.

Изменения v1.3.1: на широком экране закреплён правый блок предпросмотра, добавлена иконка. app.js полностью совпадает с оригиналом v1.3. Все функции и форматы проектов сохранены.
