3D Workshop Suite — четыре независимые программы для Windows x64

01_PlaqueMaker3D — v1.3.1
02_DrawingMaker3D — v0.6.0 FIXED3
03_FurnitureMaker3D — v0.2.3
04_FurniturePlanner3D — v0.1.3

Каждая папка содержит самостоятельный комплект сборки Windows Setup. Это не готовые EXE. Запускай BUILD_SETUP.bat только для нужной программы, следуя её README. Для первых, третьей и четвёртой программ нужен Node.js; DrawingMaker использует Python, Tesseract и Inno Setup. Интернет нужен при сборке. Уже установленные программы не требуется переустанавливать. Исходные файлы остальных трёх программ перенесены из прежних архивов без изменений.
