# 3D Workshop Suite — first Windows release

Four independent desktop applications for Windows x64. Download and install only the tools you need.

- PlaqueMaker 3D 1.3.1 — signs and labels.
- DrawingMaker 3D 0.6.0 (FIXED3 build) — supported drawing-to-model conversion.
- FurnitureMaker 3D 0.2.3 — scale furniture modules.
- Furniture Planner 3D 0.1.3 — furniture layouts and printable assembly schemes.

No account or subscription is required by the applications. Use a slicer for 3D printing. Read the individual guides for limitations and setup.
