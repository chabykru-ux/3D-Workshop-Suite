# PlaqueMaker 3D — 1.3.1

[English](README.md) · [Общий комплект](../README.ru.md)

Создание персональных табличек, визиток, дверных номеров и фирменной маркировки. Два вида табличек: обычная и с отдельным правым полем. Настраиваются размеры, скругления, бортик, надписи, шрифты, разделительные линии и цвета. Есть живой 3D-предпросмотр. Русский, английский и иврит поддерживаются при наличии подходящих шрифтов.

### Быстрый старт
1. Выберите тип таблички и введите размеры в миллиметрах.
2. Введите надписи, настройте шрифты, расположение и цвета. Справа можно указать номер, текст или символ.
3. Сохраните редактируемый проект JSON при необходимости.
4. Экспортируйте 3MF для цветных частей или STL для единой геометрии.
5. Откройте файл в слайсере, назначьте катушки и проверьте мелкие надписи и слои.

Системные шрифты зависят от Windows. Собственные TTF/OTF импортируются на текущий сеанс; при повторном открытии проекта их нужно загрузить снова. Тонкие штрихи могут не пропечататься. Углублённый текст не образует отдельной цветной части.

### Установка и сборка Windows

Установите `PlaqueMaker3D-Setup-1.3.1-x64.exe` из Releases после публикации файла. Для установленного приложения отдельно ставить инструменты сборки не требуется. Для сборки из исходников: Node.js LTS с npm и интернет для получения зависимостей. Сборка использует Electron и electron-builder. Запустите `BUILD_SETUP.bat`, результат ожидается в `dist/`. См. [оригинальную инструкцию сборки](README_WINDOWS_RU.txt).
