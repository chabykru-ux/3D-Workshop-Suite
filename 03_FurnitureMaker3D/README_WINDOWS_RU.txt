FurnitureMaker 3D v0.2.3 — Windows x64

1. Распаковать архив полностью.
2. При необходимости установить Node.js LTS (https://nodejs.org/).
3. Запустить BUILD_SETUP.bat. При сборке требуется интернет.
4. В dist появится FurnitureMaker3D-Setup-0.2.3-x64.exe.
5. Установить обычным способом. После установки интернет и Node.js для работы не нужны.

Библиотека браузера автоматически не переносится: экспортировать JSON из старой версии, импортировать в установленной программе.
Для быстрой проверки без сборки открыть app/index.html.
Установщик не подписан сертификатом; Windows может показать предупреждение.
