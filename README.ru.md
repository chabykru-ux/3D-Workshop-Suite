# 3D Workshop Suite

[English](README.md)

**Четыре независимые программы для Windows: 3D-печать, мебельные макеты и монтажные схемы.**

Комплект предназначен для частных пользователей, небольших мастерских и мебельных предприятий. Приложения ориентированы на работу за компьютером, не требуют регистрации, рекламы или подписки и рассчитаны на автономную работу после установки.

| Программа | Версия | Назначение |
| --- | --- | --- |
| [PlaqueMaker 3D](01_PlaqueMaker3D/README.ru.md) | 1.3.1 | Таблички, визитки, фирменная маркировка |
| [DrawingMaker 3D](02_DrawingMaker3D/README.ru.md) | 0.6.0 (сборка FIXED3) | Преобразование поддерживаемых чертежей в 3D-модели |
| [FurnitureMaker 3D](03_FurnitureMaker3D/README.ru.md) | 0.2.3 | Масштабные модели мебели и библиотека модулей |
| [Furniture Planner 3D](04_FurniturePlanner3D/README.ru.md) | 0.1.3 | Расстановка мебели в помещении и печать монтажных схем |

## Как использовать комплект

1. Снимите размеры помещения, составьте первоначальный эскиз.
2. Создайте необходимые шкафы и столешницы в FurnitureMaker 3D, сохраните их в библиотеке.
3. Экспортируйте модули для 3D-печати физического макета или импортируйте их в Furniture Planner 3D для расстановки и печати схемы на бумаге.
4. При необходимости используйте DrawingMaker 3D для простых технических изделий, а PlaqueMaker 3D — для табличек и маркировки.

Программы не объединены в одно приложение. Устанавливайте только нужные. STL/3MF передаются в слайсер (например, Creality Print), а не непосредственно на 3D-принтер. Furniture Planner использует обычный принтер Windows или виртуальный PDF-принтер.

## Установка Windows x64

Готовые установщики следует искать в разделе Releases после их публикации. Названия файлов приведены в [английском README](README.md#windows-installation) и индивидуальных инструкциях. Установщики без цифровой подписи могут вызвать предупреждение SmartScreen; проверяйте происхождение файла.

## Сборка из исходного кода

В каждой папке — независимый комплект сборки и `BUILD_SETUP.bat`. Следуйте индивидуальной инструкции. Интернет нужен для получения зависимостей при сборке. Три приложения используют Electron, DrawingMaker — Python, Tesseract OCR, PyInstaller и Inno Setup.

## Ограничения

Комплект не заменяет универсальную CAD/CAM-систему и не управляет CNC. Перед печатью проверяйте размеры, геометрию и нарезку. Монтажные схемы дополняют рабочие чертежи, но не заменяют их. Номера версий сохранены без искусственного повышения до 1.0.

## Лицензии

Исходники включены для ознакомления. Лицензию проекта должен выбрать автор до предоставления права на распространение и изменение. Сторонние компоненты сохраняют свои лицензии. Системные шрифты Windows не включены; импортируйте только шрифты, которые разрешено использовать.
